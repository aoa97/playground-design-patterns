# Playground Design Patterns

A Flutter project demonstrating various Gang of Four (GoF) design patterns with practical examples.

## Design Pattern Branches

### Various Exercises
- [**Multi-Pattern Playground**](https://github.com/AhmedUsama97/playground-design-patterns/tree/multi-pattern-playground) - Add multi patterns exercises
- [**Combined Pattern: Singleton, Builder, Adapter, Observer**](https://github.com/AhmedUsama97/playground-design-patterns/tree/combined/singleton_builder_adapter_observer) - Combined patterns implementation

### Creational Patterns
- [**Factory & Abstract Factory**](https://github.com/AhmedUsama97/playground-design-patterns/tree/gof/creational/factory_and_abstract_factory) - Apply abstract factory pattern in auth example
- [**Singleton Pattern**](https://github.com/AhmedUsama97/playground-design-patterns/tree/gof/creational/singleton_pattern) - Singleton pattern implementation
- [**Builder Pattern**](https://github.com/AhmedUsama97/playground-design-patterns/tree/gof/creational/builder_pattern) - Builder pattern implementation
- [**Prototype Pattern**](https://github.com/AhmedUsama97/playground-design-patterns/tree/gof/creational/prototype_pattern) - Prototype pattern implementation

### Structural Patterns
- [**Decorator Pattern**](https://github.com/AhmedUsama97/playground-design-patterns/tree/gof/structural/decorator_pattern) - Add Coffee and Tea Beverage categories
- [**Bridge Pattern**](https://github.com/AhmedUsama97/playground-design-patterns/tree/gof/structural/bridge_pattern) - Flight booking example as an application
- [**Adapter Pattern**](https://github.com/AhmedUsama97/playground-design-patterns/tree/gof/structural/adapter_pattern) - Adapter pattern implementation

### Behavioral Patterns
- [**Observer Pattern**](https://github.com/AhmedUsama97/playground-design-patterns/tree/gof/behavioral/observer_pattern) - Observer pattern implementation
- [**Template Method Pattern**](https://github.com/AhmedUsama97/playground-design-patterns/tree/gof/behavioral/template_method_pattern) - Apply template method pattern in cv report example
- [**Strategy Pattern**](https://github.com/AhmedUsama97/playground-design-patterns/tree/gof/behavioral/strategy_pattern) - Checkout example - Strategy pattern

---
